タイピングゲーム

Overview

Pythonで制作したコンソール型のタイピングゲームです。
1人でプレイするモードと2人で対戦するモードがあり、英語・日本語の単語を使ってタイピングを行うことができます。
また、ゲームの結果をファイルに保存したり、オリジナルの単語を追加したりすることもできます。

Information

作品名 タイピングゲーム
制作期間 約一ヶ月
使用技術 Python / VS Code

Features

  • 1人プレイ
  • 2人プレイ
  • 単語管理
  • 結果確認

Points

機能ごとにPythonファイルを分け、処理を整理しました。
例えば、1人プレイ・2人プレイ・単語管理・結果表示などをそれぞれ別のファイルに分けています。

また、単語の読み込みやユーザー入力のチェックなど、複数の場所で使用する処理は関数としてまとめ、他のファイルから利用できるようにしました。

Reflection

複数のPythonファイルを連携させる際に、ファイルの構成やモジュールの読み込みについて理解する必要があり、難しかったです。

また、ゲーム結果をテキストファイルに保存する処理を実装することで、Pythonによるファイルの読み書きについて学びました。
