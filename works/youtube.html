トレーニング記録アプリ

Overview

日々のトレーニングの記録を管理し、自分の頑張りを可視化するために制作したWebアプリです。
「どのくらい継続できているか」を確認できるようにし、記録を振り返りながら継続して取り組めることを目的としています。

Information

作品名 トレーニング記録アプリ
制作期間 3週間
使用技術 HTML / CSS / JavaScript

Features

  • トレーニングをしたかの記録
  • トレーニング動画の再生
  • トレーニングの達成状況の表示
  • 継続日数の表示
  • カレンダーによる記録の確認
  • ブラウザへの記録データの保存
  • トレーニング内容の切り替え

Points

連続してトレーニングを行った日数を表示することで、「これだけ続けられている」ということを目で確認できるよう工夫しました

また、タブでジャンルを分けることで、
今日は疲れているけど、これだけでもやっておこうという風に、トレーニングに取り組みやすくしました。

Reflection

記録の保存方法について、当初はDBへの保存も検討しましたが、
今回の制作規模と開発環境を考慮し、ブラウザ内にデータを保存する方法を選択しました。
限られた環境の中で、必要な機能を実現するためにどの方法が適切かを考えるよい経験になりました。
